## Stack utilizada

**Front-end:** TypeScript, Expo, React Native, Context API, NativeWind(tailwindcss), Reanimated, 

**Back-end:** Node, Express, Firebase, Prisma, Helmet, Yup




## Rodando localmente

Clone o projeto

```bash
  git clone https://github.com/rubensalbukrk/vanyVisionCommerce
```

Entre no diretório do projeto

```bash
  cd my-project
```

Instale as dependências

```bash
  npm install
```

Inicie o servidor

```bash
  expo start
```
